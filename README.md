# AmenoRica · Astro + Pages CMS

Astro로 빌드해 GitHub Pages에 배포하는 홈페이지와 블로그 소스입니다.
홈페이지의 최신 로컬 파일을 `public/`에 보존하고 블로그만 Astro 템플릿으로 옮겼습니다.
샘플 글은 전부 삭제했습니다. 첫 글을 작성하기 전까지 목록은 비어 있습니다.

## 글 작성

최초 연결 후 https://app.pagescms.org 에 GitHub로 로그인하고 `AmenoRica/AmenoRica.github.io` 저장소와 `main`을 선택합니다.

1. **블로그 글 → 새 글**을 엽니다.
2. 제목, 선택 사항인 부제목, 첫 작성일, 카테고리, 본문을 입력합니다. 본문은 서식 있는 편집기와 Markdown 원문 모드를 사용할 수 있습니다.
제목 입력란에서 Enter로 줄을 나누면 본문 페이지의 제목에만 반영됩니다. 목록과 브라우저 탭 제목에서는 공백으로 이어집니다. 좁은 화면에서는 자동 줄바꿈도 유지됩니다.

3. 이미지 업로드는 `public/uploads`에 저장됩니다.
4. 공개하려면 **초안**을 끄고 저장합니다. 저장하면 GitHub 변경 기록이 생성되고 자동 빌드가 성공한 후 사이트에 나타납니다.
5. 기존 글을 다시 열어 수정하고 저장하면 같은 주소의 글이 갱신됩니다. 파일 이름은 주소이므로 작성 후 바꾸지 않는 것이 좋습니다.

첫 작성일은 처음 입력한 값을 유지합니다. 마지막 수정일은 별도 입력 없이 해당 글 파일의 Git 저장 기록으로 계산합니다. 최초 저장은 수정으로 세지 않으며, 두 번째 저장부터 최신 저장 날짜를 한국 시간으로 표시합니다. 첫 작성일과 같은 날이면 숨깁니다. 본문에서만 `2026.11.06.에 마지막 수정` 형태로 표시하고 목록에는 첫 작성일만 표시합니다. 글 제목·카테고리·초안 여부 변경도 해당 글의 저장으로 취급합니다. 로컬에서 저장만 하고 Git에 반영하지 않은 변경은 수정일에 반영되지 않습니다.

카테고리 메뉴에서 새 카테고리를 추가할 수 있습니다. 식별자는 영문 소문자·숫자·하이픈을 사용하고 `all`은 사용하지 않습니다. 글이 참조하는 식별자는 변경하거나 삭제하지 마세요. 새 로고 이미지를 업로드하거나 기존 로고 서체를 선택합니다. ALL은 사이트가 자동으로 맨 앞에 제공합니다.

## 최초 연결

- 이 폴더의 소스를 기존 저장소에 반영합니다. 이전 루트의 정적 홈페이지 파일은 `public/` 아래로 이동하는 구조입니다. 빌드 결과인 `dist/` 또는 `node_modules/`를 소스로 올리지 않습니다.
- GitHub 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 설정합니다. 기존 도메인 `ameno.cc`와 DNS는 유지합니다.
- Pages CMS의 GitHub App을 **이 저장소만 선택하여** 설치·승인합니다. 저장소의 글과 이미지를 저장할 수 있는 권한이 필요합니다.
- `.pages.yml`이 저장소 루트에 보이면 CMS가 글 작성 화면을 구성합니다.
- 실제 첫 글 저장 → Actions 성공 → 공개 사이트 반영까지 확인합니다.

CMS 로그인·권한 승인과 실제 CMS 저장은 별도 확인이 필요합니다.
공개 저장소에서는 초안 파일도 GitHub 방문자가 읽을 수 있습니다. 초안 기능은 블로그에 표시하지 않는 기능입니다.

## 로컬 개발

Node.js 24 이상 권장.

```sh
npm ci
npm test
npm run dev
npm run build
npm run preview
```

`src/content/posts/*.md`: 글 · `src/content/categories/*.json`: 카테고리 · `src/pages/blog`: 화면 · `public/blog`: 기존 물리/테마/목록 코드.
`public/`의 홈페이지는 기존 정적 파일이며, 홈페이지 수정은 여기서 진행합니다.
GitHub Actions는 수정일 계산을 위해 전체 Git 기록을 가져옵니다(`fetch-depth: 0`).
현재 템플릿의 기존 `noindex` 설정은 유지되어 있습니다.

공식 문서: https://pagescms.org/docs/quick-start/ · https://pagescms.org/docs/configuration/ · https://docs.astro.build/en/guides/deploy/github/
